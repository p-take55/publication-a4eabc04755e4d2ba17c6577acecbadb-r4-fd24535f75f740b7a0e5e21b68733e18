# 公開検証：調査と会議のアシスタント

このAgentは、架空データによるDiscoverの公開動作を検証するための検証用Agentです。

調査資料や会議記録を、読み手が判断し行動できる形にまとめる日本語のAgentです。

## できること

- 調査：目的と比較条件を確認し、出典付きの根拠、選択肢、次のアクションを整理します。
- 会議要約：記録から決定事項、未解決の論点、次のアクションを抽出します。記載のない担当や期日は「未定」とします。

## 使い方

Agentとして導入し、目的、読み手、対象資料、分かっている制約を伝えてください。

依頼例：

- 「以下の資料をもとに、営業チーム向けに選択肢を比較し、要点・根拠・次のアクションをまとめてください。予算は未定です。」
- 「この会議記録から決定事項、未解決の論点、担当と期日を含む次のアクションを整理してください。」

## 同梱ファイル

- `identity.md`：Agentの役割と作業方針
- `.agents/skills/research-brief/SKILL.md`：調査を簡潔な提案資料にまとめる手順
- `.agents/skills/meeting-summary/SKILL.md`：会議記録を整理する手順
- `knowledge/report-format.md`：調査資料の共通書式
- `.aachat/public.yaml`：Discover向けの公開プロフィール

両SkillはAgentに同梱し、Discoverの単体Skillとしては掲載しない設定です。調査SkillはAgentルートの `knowledge/report-format.md` を参照するため、上記の構成を保持してください。

## 利用環境とデータ

追加のPlugin、パッケージ、APIキーは必須ではありません。提供された資料だけでも利用できます。最新のWeb調査には利用環境の検索・閲覧機能、または利用者が提供する出典資料が必要です。外部サービスへ接続する場合は利用者自身の環境で認証と必要な権限を設定してください。

会社固有の運用ルール、顧客メモ、固定の共有先、認証情報は同梱していません。資料は利用権限のあるものを指定してください。外部への送信や共有設定の変更には明示的な依頼が必要です。情報に不足がある場合は不足を示し、出典や未確定の条件を作りません。
