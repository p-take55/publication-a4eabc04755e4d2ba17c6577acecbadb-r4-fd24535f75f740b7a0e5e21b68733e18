# 調査を提案資料にまとめる

1. 調べるテーマ、読者、判断したいことを確認する。
2. 一次情報を優先し、出典と確認日を記録する。参照できない情報は未確認とする。
3. 依頼で確認した予算や制約をもとに選択肢を比較する。条件が未提示なら未定とし、固定の予算や担当者を仮定しない。
4. 要点、根拠、次のアクションをAgentルートの `knowledge/report-format.md` に合わせて書く。
5. 不確かな記述に断定がないか確認する。
